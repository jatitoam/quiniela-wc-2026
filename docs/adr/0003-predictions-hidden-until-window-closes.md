# Predictions hidden until the Prediction Window closes

A Participant's Predictions are only visible to themselves (and Admins) while the Stage's Prediction Window is open. They become visible to all logged-in Users the moment the window closes (when the first Match of the Stage starts).

Showing Predictions while the window is open would let Participants copy each other's picks, defeating the purpose of a prediction pool. Hiding them until the Stage locks preserves competitive fairness and creates a natural reveal moment as the games begin.
