# Score 30-minute correction window

Scores are editable by an Admin for 30 minutes after entry, then become immutable. The spec originally called for full immutability, but a typo in a Score (e.g. 2–1 instead of 1–2) would permanently corrupt every Participant's Points with no recourse. A full audit trail (editable at any time) was rejected as it opens the door to result manipulation. The 30-minute window is long enough to catch input errors but short enough that nobody can adjust a Score after checking social media reactions.

Points are recalculated automatically if a Score is corrected within the window.
